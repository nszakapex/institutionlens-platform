## Permission matrix

| Permission                 | Analyst | Reviewer | Administrator |
| -------------------------- | ------: | -------: | ------------: |
| `organization:read`        |     Yes |      Yes |           Yes |
| `assessment:read`          |     Yes |      Yes |           Yes |
| `evidence:read`            |     Yes |      Yes |           Yes |
| `evidence:restricted_read` |      No |       No |           Yes |
| `methodology:read`         |     Yes |      Yes |           Yes |
| `overlay:read`             |     Yes |      Yes |           Yes |

The application requires both the permission in the context and permission in the role policy. `OrganizationPublicRef`, noindex metadata, security headers, and redacted URLs are not authorization mechanisms.

## Phase boundary

Phase 6 implements read-only synthetic organization detail, evidence/provenance catalog, methodology presentation, lineage projection, and minimized private overlay UI. It does not implement real ingestion, database persistence/RLS, production authentication, comparison, briefs, exports, notes, mutations, deployment, or production performance validation.

Phase 7 has not started.
