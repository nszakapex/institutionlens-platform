# InstitutionLens Primary Brand

The selected InstitutionLens frontend and expanded brand system.

## Open locally

1. Extract the package.
2. Open `index.html` for the business frontend.
3. Open `brand-kit.html` for the visual brand system.

No package installation, build process or environment variables are required. The site uses static HTML, CSS and JavaScript with locally bundled fonts and imagery.

## Included

- Complete responsive business frontend
- Interactive Digest, Universe and Account product views
- Custom InstitutionLens optical mark
- Animated institutional financial-field SVG
- Animated explainable fit-signal SVG
- SVG Observe, Focus and Act method graphics
- Pilot, deployment/security and FAQ sections
- Visual brand-system presentation
- Written positioning, identity, typography, color, data-visualization, motion and voice standards

## Main files

- `index.html` — primary product website
- `brand-kit.html` — visual brand presentation
- `BRAND-KIT.md` — written brand standards
- `styles.css` — shared product system
- `brand-kit.css` — brand presentation layer
- `script.js` — product interactions and motion
- `assets/` — mark, financial SVG system, fonts and hero artwork

## Deployment

This can be deployed as a static site on Vercel, Netlify or GitHub Pages. Use the package root as the publish directory. No build command is needed.

The pilot form is a frontend prototype and intentionally does not transmit data. Connect it to an approved form endpoint or serverless function before production use.
